# Memory Game

Memory Game - браузерная игра на поиск парных карточек.

Игрок открывает две карточки за ход и старается найти все совпадающие пары. Если изображения совпали, карточки остаются открытыми. Если изображения разные, они закрываются через короткую задержку. Игра заканчивается, когда найдены все 8 пар.

## Что реализовано

- 16 карточек: 8 пар с изображениями на тему космоса.
- Случайное перемешивание карточек при загрузке и новой игре.
- Счётчик ходов и найденных пар.
- Новая игра без перезагрузки страницы.
- Модальное окно победы.
- Таблица лидеров с сохранением результатов в `localStorage`.
- Закрытие модальных окон кнопкой, кликом по фону и клавишей `Escape`.

## Локальный запуск

Проект загружает данные карточек из `cards.json`, поэтому его нужно запускать через локальный сервер.

1. Перейдите в папку проекта:

```bash
cd "Memory Game"
```

2. Запустите локальный сервер:

```bash
python3 -m http.server 5500
```

3. Откройте приложение в браузере:

```txt
http://localhost:5500
```

Если порт `5500` занят, можно указать другой порт:

```bash
python3 -m http.server 5501
```

Тогда приложение будет доступно по адресу:

```txt
http://localhost:5501
```
